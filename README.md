## 🚀 What I'm Building

### 🎙️ Vocaa — Speak. Connect. Grow.

A real-time language-practice platform that pairs learners with native speakers in under 2 seconds for 5-minute voice sessions. Currently in **Google Play closed testing**.

**Stack:** NestJS · PostgreSQL (Supabase) · Redis (Upstash) · React Native (Expo) · LiveKit (WebRTC) · OpenAI Whisper · GPT-4o · Prisma · Railway · EAS

**What I built:**
- WebSocket-based matchmaking queue with Redis (sub-2s pairing)
- LiveKit WebRTC integration for HD voice with low latency
- AI pronunciation feedback pipeline using Whisper transcription + GPT-4o coaching
- Cross-platform mobile app with Google OAuth + JWT auth
- 49 seeded topics, 3 scheduled rooms, full Prisma migration setup

🔗 [Live site](https://vocaappcom.vercel.app)

---

### 🪬 Milap — The Ancient Ritual, Reborn

A dating app that replaces infinite swiping with a sacred game. Two compatible souls search the same milk for one ring during a 30-minute nightly window. Identity reveals slowly: anonymous chat → name → photo → commitment.

**Stack:** Next.js · Node.js · MongoDB · Tailwind · Vercel

**What I built:**
- Blind matching engine with quiet compatibility scoring
- Progressive reveal system (Day 0 → Day 15 timeline)
- Daily 30-minute "Kund" matching window
- 2,400+ waitlist signups before public launch

🔗 [Live site](https://milap-eta.vercel.app)
